Behind the numbers

How Prompt Pond works.

The activity chart describes your export. The water card is an illustration based on an adjustable assumption.

What gets counted?

For ChatGPT conversation JSON, we count distinct messages whose author role is user. If a message has a valid timestamp, it contributes to daily charts and streaks. Messages without a usable timestamp contribute to the total only. We count a prompt once even if the export contains duplicate message IDs.

Manual input is a self-reported total. It has no dated history. The site does not infer model, tokens, topic, server location, or actual energy use.

What does the water card mean?

Illustrative water (mL) = number of prompts × selected mL per prompt. The default, 0.32 mL, is approximately 0.000085 US gallons, described publicly as an average ChatGPT query. That statement does not publish the measurement boundary or a per-user method. Your real usage may differ substantially. Change the slider to see how the assumed rate changes the result.

The bottle and glass cards compare volumes only. A crop's water footprint includes different processes, so we do not treat it as equivalent to data-centre cooling water. This project does not measure an individual's environmental footprint.

Where does your data go?

The browser parses the JSON locally. The full file and chat text are never sent to the Worker. If you select Save summary, the backend stores the total and daily counts under a random browser key. The key is kept in this browser's local storage. Anyone with that key can access or delete that summary, so avoid sharing it. You can delete the server copy from the dashboard. Clearing browser storage removes your access to any saved summary.
